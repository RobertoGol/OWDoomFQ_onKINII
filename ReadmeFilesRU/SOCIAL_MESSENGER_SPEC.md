# 💬 Спецификация социальной сети, защищенного мессенджера и аудио-комнат (SOCIAL_MESSENGER_SPEC.md)

Настоящий документ определяет сетевую архитектуру, структуры баз данных и протоколы криптографии для встроенной экосистемы **Социальной Сети и Мессенджера**. Подсистема объединяет в себе функционал современных платформ (**Telegram / Discord / VK**): профили пользователей со стеной постов, алгоритмическую ленту новостей, каналы гильдий, личные и групповые чаты со сквозным шифрованием (E2EE), голосовые комнаты (Voice Lounges) и стриминг музыки.

Главная цель данной подсистемы — создать единое социальное пространство, где игроки в **UZDoom на ПК** и пользователи **Мобильного приложения на Android** общаются в одном мессенджере без разрыва сессии, делятся игровыми трофеями на стене профиля и координируют действия в голосовых комнатах под защитой рантайма **KINII (`void.run`)**.

---

## 🏗️ 1. Системные и архитектурные связи

Социальная платформа является главным связующим звеном между игровым клиентом и внешним миром через перекрестные ссылки:
* **Криптография и изоляция переписки:** Ключи шифрования личных диалогов, кэш голосовых сообщений и токены авторизации живут исключительно в защищенной памяти Ghost-RAM через [memory.ctos](../Lang_for_my_decisions/memory.ctos).
* **База данных соцсети (Посты, Лайки, История):** Вся графовая база друзей, посты на стенах и зашифрованная история чатов хранятся в скрытых секторах `HiddenVault` под управлением [sql.core](../Lang_for_my_decisions/sql.core).
* **Сквозной мост с игрой (In-Game Overlay):** Перехват сообщений из консоли/оверлея UZDoom и их мгновенная отправка в мобильный мессенджер выполняются через [bridge.ctos](../Lang_for_my_decisions/bridge.ctos) и описаны в [BRIDGE_SPEC.md](./BRIDGE_SPEC.md).
* **Интеграция игровых предметов в посты:** Игрок может прикрепить к посту в соцсети или сообщению в чате «живую карточку» своей пушки из [INVENTORY_SPEC.md](./INVENTORY_SPEC.md), чтобы друзья могли покрутить её характеристики прямо на экране телефона.
* **Сообщества Гильдий:** Структура клановых серверов, ролей доступа (Админ, Модератор, Участник) и синхронизация со списком друзей базируются на [CLAN_SPEC.md](./CLAN_SPEC.md).
* **Клиентские интерфейсы:** Верстка ленты новостей, мессенджера, стикеров и профилей на Android лежит в папке [View/](../Lang_for_my_decisions/View/) и спецификации [COMPANION_APP.md](./COMPANION_APP.md).

## 📊 2. Бинарные структуры Социальной Сети и Мессенджера

Для мгновенной подгрузки ленты постов и сообщений чата без задержек, все объекты соцсети сериализуются в строгие бинарные контейнеры.

### 2.1 Структура поста в ленте соцсети (Social Feed Post) - 128 байт + медиа
```

    void
    struct SocialPostNode {
        u64 post_uuid;              // Уникальный идентификатор публикации в глобальной ленте
        u32 author_player_id;       // ID автора поста (привязан к профилю в CLAN_SPEC.md)
        u64 timestamp_utc;          // Время публикации
        u8  post_type;              // 0x01 = Текст, 0x02 = Скриншот из игры, 0x03 = Хвастовство лутом (Item Embed)
        
        // Интерактивная привязка к игре:
        u64 attached_item_uuid;     // Если тип 0x03 — ссылка на реальную пушку из INVENTORY_SPEC.md
        i32 location_chunk_xy;   // Гео-тег чанка открытого мира (MAP_SPEC.md), где был сделан пост/скриншот
        
        // Социальная статистика (обновляется в реальном времени через sql.core):
        u32 likes_count;            // Количество лайков / реакций
        u32 comments_count;         // Количество комментариев под постом
        u32 reposts_count;          // Количество пересылок в чаты мессенджера
        
        u32 media_blob_ptr;         // Указатель на сжатое изображение/видео или текст в хранилище
        u32 post_signature_crc;     // Цифровая подпись автора (защита от фейковых постов от чужого имени)
    }

```

### 2.2 Универсальный пакет сообщения Мессенджера (Messenger Chat Packet)
```

    void
    struct MessengerEnvelope {
        u64 message_uuid;           // Уникальный ID сообщения в чате
        u64 chat_room_id;           // ID диалога (Личка 1-на-1, Группа пати из 4 чел., или Канал Гильдии)
        u32 sender_id;              // ID отправителя
        u64 reply_to_msg_uuid;      // ID сообщения, на которое отвечают (0 = обычное сообщение)
        
        u8  content_type;           // 0x01=Текст, 0x02=Голосовое (Voice), 0x03=Стикер, 0x04=Торговый оффер
        u8  delivery_status;        // 0x01=Отправлено, 0x02=Доставлено, 0x03=Прочитано (Две галочки)
        u8  encryption_mode;        // 0x01=E2EE (Секретный чат), 0x02=Серверное шифрование канала
        
        u8  aes_iv;             // Вектор инициализации для шифра AES-GCM-256
        u32 payload_length;         // Длина зашифрованного контента
        u8  encrypted_payload[];    // Зашифрованный текст, аудио-войс (Opus) или карточка предмета
    }

```

## 🌐 3. Архитектура Социальной Сети (Профили, Стена, Лента и Трофеи)

Социальная сеть построена вокруг достижений игрока в открытом мире и его взаимодействия с комьюнити:

### 3.1 Личная страница игрока (User Wall & Bio)
Каждый пользователь имеет кастомизируемый профиль (аватарка, баннер, статус, список друзей, витрина редких вещей):
* **Авто-шеринг из UZDoom в один клик:** Когда игрок в игре выбивает оранжевую легендарную пушку ([WORLD_DESIGN.md](./WORLD_DESIGN.md)) или зачищает сложный рейд, в углу экрана появляется кнопка «Опубликовать в Ленту». Движок делает рендер-скриншот, прикрепляет к нему интерактивную 3D-карточку оружия (`attached_item_uuid`) и через `bridge.ctos` мгновенно публикует пост на стене игрока.
* **Интерактивные вложения (Rich Embeds):** Друзья, листая ленту соцсети в приложении на смартфоне, видят этот пост. Они могут нажать на прикрепленную пушку прямо в посте, посмотреть её точные модули из `WEAPON_CRAFT_SPEC.md`, поставить лайк или нажать кнопку **«Предложить обмен»**, что сразу откроет окно безопасной сделки в мессенджере!

### 3.2 Система Друзей и Статусов присутствия (Rich Presence)
Список друзей синхронизирован между ПК и телефоном. В профиле каждого друга в реальном времени отображается детальный статус:
* 🟢 **В сети (В приложении):** *«Листает ленту / Сидит в чате торговли»*.
* 🎮 **В игре (UZDoom):** *«На сервере [Ru-Battlefield #1] | В чанке [X:4, Y:-2] | В группе (2/4) — Присоединиться»*. Нажав кнопку в профиле друга, игрок может сразу подключиться к его P2P-сессии ([SERVER_BROWSER_SPEC.md](./SERVER_BROWSER_SPEC.md)).

## 💬 4. Функционал Защищенного Мессенджера (Telegram / Discord Style)

Мессенджер разделен на три уровня коммуникации, которые одинаково доступны как в мобильном приложении `View/`, так и во внутриигровом оверлее UZDoom (вызывается по `Shift + Tab` или в окне чата):

```

    ┌──────────────────────────────────────────────────────────────────────────┐
    │                     АРХИТЕКТУРА КАНАЛОВ МЕССЕНДЖЕРА                      │
    ├───────────────────────┬──────────────────────────┬───────────────────────┤
    │   1. ЛИЧНЫЕ ЧАТЫ      │    2. ГРУППЫ ОТРЯДА      │  3. СЕРВЕРЫ ГИЛЬДИЙ   │
    │ • Сквозное E2EE       │ • До 4-8 человек (Пати)  │ • Текстовые ветки     │
    │ • Голосовые (Войсы)   │ • Общий тактический пинг │   (#новости, #рынок)  │
    │ • Секретные таймеры   │ • Синхронизация с игрой  │ • Голосовые комнаты   │
    │ • Прямой P2P-Трейд    │ • Быстрый созвон группы  │   (Voice Lounges)     │
    └───────────────────────┴──────────────────────────┴───────────────────────┘

```


1. **Личные сообщения (DM) и Секретные чаты:** Полное сквозное шифрование (End-to-End) на протоколе Диффи-Хеллмана (Curve25519). Ни сервер игры, ни бэкенд `deploy_hub.vc` не имеют ключей расшифровки. Поддерживаются текстовые ответы (Replies), реакции-эмодзи, кастомные стикерпаки игры, запись голосовых сообщений и таймер самоуничтожения переписки в `Ghost-RAM`.
2. **Чаты Группы (Party Chat):** Когда игроки объединяются в кооператив (Borderlands-стиль до 4 человек), мессенджер автоматически создает временную групповую беседу. Все, что игрок пишет во внутриигровой чат пати в UZDoom, мгновенно прилетает пуш-сообщением в эту группу на смартфонах остальных участников.
3. **Хабы Гильдий (Discord-подобные серверы кланов):** Каждый клан из [CLAN_SPEC.md](./CLAN_SPEC.md) получает свой многоканальный сервер внутри мессенджера. Лидер клана создает тематические ветки: `#общий-чат`, `#оповещения-осад` (куда бот сервера шлет отчеты об атаках на базу из [MAP_SPEC.md](./MAP_SPEC.md)), `#торговая-площадка` и закрытый `#совет-офицеров`.

## 🎧 5. Голосовые комнаты (Voice Rooms) и Музыкальный плеер соцсети

Никаких радиопомех и ручной настройки частот — голосовое общение работает по современному стандарту кристально чистого звука (кодек **Opus 48 кГц Stereo** с умным шумоподавлением):

* **Голосовые комнаты (Drop-in Voice Channels):** Внутри сервера гильдии или группового чата есть постоянные голосовые комнаты (например, *«Комната Рейда #1»*). Игрок может зайти в голосовую комнату как с ПК (во время игры), так и со смартфона. При этом внутри UZDoom поверх экрана рисуется аккуратный виджет: аватарки говорящих друзей подсвечиваются зеленым кружком.
* **Пространственный звук в кооперативе (Proximity Audio):** Внутри самой игры голоса участников комнаты могут плавно позиционироваться по 3D-координатам их персонажей, чтобы игрок на слух понимал, слева или справа от него бежит напарник.
* **Встроенный Музыкальный Стриминг (Совместное прослушивание):** В профиль соцсети встроен аудио-плеер. Игроки могут загружать свои плейлисты, слушать фоновую музыку пустоши, подкасты разработчиков или включать **«Музыкального бота»** прямо в голосовой комнате чата, чтобы вся пати из 4 человек во время поездки на машине ([VEHICLE_SPEC.md](./VEHICLE_SPEC.md)) слушала один и тот же трек синхронно!
