# 🔫 Спецификация модульного конструктора оружия и физической баллистики (WEAPON_CRAFT_SPEC.md)

Настоящий документ определяет математическую модель внешней и терминальной баллистики снарядов, а также архитектуру модульной сборки вооружения. Подсистема объединяет процедурную генерацию миллионов комбинаций деталей от разных корпораций-производителей из **Borderlands 2**, глубокую кастомизацию и пересборку оружия на верстаках из **Fallout 4** и честную физику полета пули (гравитация, время подлета, баллистический коэффициент, пробитие преград) на огромных дистанциях из **Battlefield**.

Главная цель данной подсистемы — заменить примитивные мгновенные лучи (Hitscan) оригинального движка Doom 2 на полноценную физическую симуляцию снаряда для боев в открытом мире на дистанциях свыше $4096$ юнитов, обеспечив криптографическую защиту кастомных сборок оружия от читерской модификации через **KINII (`void.run`)**.



## 🏗️ 1. Системные и архитектурные связи

Оружейная подсистема напрямую связана с экономическими, пространственными и социальными модулями проекта через систему перекрестных ссылок:
* **Генерация дропа и редкости:** Базовый спавн оружия в сундуках и вероятностные матрицы редкости (Common — Legendary) вызываются из [world_stream.void](./world_stream.void) и описаны в [WORLD_DESIGN.md](./WORLD_DESIGN.md).
* **Сериализация в инвентаре:** Указатель `custom_data_ptr` из общей 32-байтной структуры предмета в [INVENTORY_SPEC.md](./INVENTORY_SPEC.md) ссылается непосредственно на бинарный граф модулей данного документа в памяти `Ghost-RAM` ([memory.ctos](../Lang_for_my_decisions/memory.ctos)).
* **Сетевая синхронизация выстрела:** Проверка траектории физической пули с учетом пинга стрелка (Lag Compensation) обрабатывается сервером по правилам [MULTIPLAYER_SPEC.md](./MULTIPLAYER_SPEC.md).
* **Зональный урон по телу:** При попадании снаряда в цель расчет переломов конечностей, кровотечений и пробития брони передается в био-матрицу [SURVIVAL_SPEC.md](./SURVIVAL_SPEC.md).
* **Хвастовство и Торговля в Соцсети:** Сгенерированный хэш-код сборки пушки позволяет прикреплять интерактивную 3D-карточку оружия к постам на стене и в личных сообщениях мессенджера в [SOCIAL_MESSENGER_SPEC.md](./SOCIAL_MESSENGER_SPEC.md).



## 📊 2. Бинарная структура модульного оружия (Modular Weapon Graph)

Каждая единица оружия в игре не является статичным объектом — это конструктор, состоящий из **6 обязательных узлов (Нодов)**. Структура хранится в защищенной памяти `Ghost-RAM` и занимает ровно 64 байта.

```
    void
    struct WeaponModularGraph {
        u64 weapon_instance_uuid;   // Прямая связь с item_uuid из INVENTORY_SPEC.md
        u8  manufacturer_id;        // Производитель (Borderlands-стиль: 0x01=Kinetics, 0x02=Helios-Elem, 0x03=Titan-Explosive)
        u8  rarity_tier;            // Уровень редкости базового корпуса (0x01=Common .. 0x05=Legendary)
        
        // Идентификаторы 6 установленных модулей (Fallout 4 Workbench Nodes):
        u16 node_receiver_id;       // 1. Ресивер (определяет базовый урон, калибр патрона и темп стрельбы: авто/полуавто)
        u16 node_barrel_id;         // 2. Ствол (определяет начальную скорость пули V0, кучность и дальность)
        u16 node_grip_stock_id;     // 3. Приклад/Рукоять (гашение вертикальной и горизонтальной отдачи, скорость вскидывания ADS)
        u16 node_magazine_id;       // 4. Магазин (емкость патронов, скорость перезарядки, тип подачи: коробчатый/барабанный)
        u16 node_optic_id;          // 5. Прицел (кратность зума камеры в UZDoom: 1x Коллиматор .. 12x Баллистический, Тепловизор)
        u16 node_muzzle_elem_id;    // 6. Дульная насадка / Стихийный блок (Глушитель шума для MAP_SPEC.md, Огонь, Кислота, Шок)
        
        // Итоговые пересчитанные характеристики (кэшируются рантаймом при сборке на верстаке):
        f32 calc_base_damage;       // Итоговый кинетический урон одного снаряда
        f32 calc_muzzle_velocity;   // Начальная скорость пули V0 (в юнитах Doom в секунду)
        f32 calc_bullet_mass;       // Масса пули в граммах (влияет на импульс, падение и пробитие стен)
        f32 calc_drag_coeff;        // Коэффициент аэродинамического сопротивления воздуха
        f32 calc_spread_moa;        // Угловой разброс в угловых минутах (MOA)
        f32 calc_recoil_kick;       // Сила подброса ствола при выстреле
        
        u32 skin_shader_id;         // ID кастомной раскраски / камуфляжа оружия
        u32 graph_crc32;            // Контрольная сумма всех узлов + MASTER_HWID против подмены деталей в CheatEngine
    }

```

## 🛠️ 3. Философия производителей и Крафт на Верстаке (Borderlands + Fallout)

### 3.1 Архетипы корпораций-производителей (`manufacturer_id`)
Корпус оружия задает фундаментальное поведение пушки (в духе *Borderlands 2*):
* **`0x01` (Kinetics Corp — аналог Jakobs):** Огромный базовый физический урон и критический множитель $\times 2.5$ при попадании в голову ([SURVIVAL_SPEC.md](./SURVIVAL_SPEC.md)), но высокая отдача и стрельба со скоростью нажатия курка.
* **`0x02` (Helios Tech — аналог Maliwan):** Высокотехнологичное оружие, всегда имеющее встроенный стихийный конденсатор (`node_muzzle_elem_id` накладывает периодический урон огнем, плазмой, радиацией или коррозией, плавящей броню техники).
* **`0x03` (Titan Heavy — аналог Torgue):** Стреляет тяжелыми мини-ракетами и гиро-снарядами с низкой скоростью полета `calc_muzzle_velocity`, но наносящими взрывной урон по площади (Splash Damage) и разрушающими стены из [WORLD_DESIGN.md](./WORLD_DESIGN.md).

---

### 3.2 Алгоритм пересборки на Оружейном Верстаке
В отличие от *Borderlands*, где пушку нельзя изменить, у нас внедрена механика верстака из *Fallout 4*:
1. Игрок на базе клана открывает верстак и разбирает три ненужных автомата на запчасти.
2. Модули (`node_barrel_id`, `node_optic_id`) сохраняются как отдельные инженерные детали в инвентаре ([INVENTORY_SPEC.md](./INVENTORY_SPEC.md)).
3. Игрок берет легендарный корпус винтовки и вручную ставит на него *Длинный снайперский ствол*, *Барабанный магазин на 75 патронов* и *Глушитель*.
4. При нажатии кнопки «Собрать» рантайм `void.run` проверяет совместимость узлов, пересчитывает кэш баллистики, подписывает структуру новой суммой `graph_crc32` и сохраняет чертеж в `sql.core` (`HiddenVault`). Визуальная 3D/воксельная модель оружия в руках игрока в UZDoom мгновенно перестраивается под выбранные обвесы.

## 🎯 4. Математическая модель внешней баллистики (Battlefield Style)

Для перестрелок в открытом мире через несколько чанков мгновенные лучи (Hitscan) полностью отключены. Каждый выстрел порождает в памяти KINII легковесный математический объект снаряда, обсчитываемый ядром `void.run` с частотой $140\text{ Гц}$ (независимо от FPS рендерера UZDoom).

### 4.1 Уравнения траектории полета, ветра и падения пули (Bullet Drop)

Положение снаряда $\vec{P}(t)$ в трехмерном пространстве Doom в момент времени $t$ после выстрела вычисляется с учетом вектора начальной скорости $\vec{V}_0$, гравитации $g_{doom}$, коэффициента аэродинамического торможения $k_{drag}$ и вектора ветра в чанке $\vec{W}$:

$$P_x(t) = P_{x0} + \left( V_{0x} \cdot e^{-k_{drag} t} + W_x \right) \cdot t$$
$$P_y(t) = P_{y0} + \left( V_{0y} \cdot e^{-k_{drag} t} + W_y \right) \cdot t$$
$$P_z(t) = P_{z0} + V_{0z} \cdot t - \frac{1}{2} g_{doom} \cdot t^2$$

---

### 4.2 Схема баллистического снижения и работы сетки прицела (Mil-Dot Compensation)

Чтобы поразить цель в соседнем чанке (на дистанции $3500$ юнитов), стрелок не может наводить центр перекрестия прямо на врага — гравитация утянет пулю в землю. Стрелок обязан поднять ствол выше цели (взять вертикальную поправку по рискам оптического прицела `node_optic_id`):

```

         ▲ Точка прицеливания (Перекрестие поднято ВЫШЕ головы на 2 мил-дота)
        /
    Линия взгляда оптики (Прямой луч камеры UZDoom)
      /
     /                                     .-~^~-.   <-- Реальная парабола полета пули (Взлет и падение -1/2gt^2)
    /                                  .-~         ~-.
    [🔫 СТРЕЛОК] ───/──.-~─────────────────~-.──────────────────────► 🎯 [ПОПАДАНИЕ В ГОЛОВУ!]
        │                                                                 (Дистанция: 3500 юнитов)
        │
        └─── (Если целиться ровно по прямой в цель) ──._
                                                         ~-._
                                                              ~-._
                                                                   ▼ ❌ (ПРОМАХ В ЗЕМЛЮ ПЕРЕД ВРАГОМ)

```

* **Баллистическое упреждение:** При стрельбе на дальние дистанции (от $1500$ до $8000$ юнитов) стрелку необходимо брать вертикальную поправку по сетке прицела (Mil-Dot в UZDoom) и горизонтальное упреждение перед бегущим врагом или едущей машиной, так как пуля летит до цели от $0.2$ до $1.5$ секунд.
* **Сквозное пробитие укрытий (Wall & Armor Penetration):** Когда вектор пули пересекает стену `LineDef` из [WORLD_DESIGN.md](./WORLD_DESIGN.md), рантайм вычисляет текущую кинетическую энергию снаряда:

$$E_k(t) = \frac{1}{2} m_{bullet} \cdot |\vec{V}(t)|^2$$

Если $E_k(t) > \text{Hardness}_{wall}$ (например, крупнокалиберная снайперская пуля попадает в деревянный забор или тонкий лист железа), пуля **не исчезает**: она пробивает стену насквозь, теряя часть скорости и немного меняя угол (рикошет/девиация), и поражает врага, спрятавшегося за укрытием!

### 4.4 Терминальная баллистика: Пробитие стен и Рикошеты (Wall Penetration)

Когда математический вектор летящей пули пересекает плоскость стены `LineDef` из [WORLD_DESIGN.md](./WORLD_DESIGN.md), пуля не удаляется из памяти автоматически. Ядро KINII вычисляет остаточную кинетическую энергию снаряда в точке удара:

$$E_k(t) = \frac{1}{2} m_{bullet} \cdot |\vec{V}(t)|^2$$

1. **Сквозное пробитие (Penetration):** Если энергия пули $E_k(t)$ превышает порог плотности материала стены `Hardness` (например, выстрел из крупнокалиберной винтовки `.308 Win` по деревянной баррикаде или тонкому железному забору) и угол встречи близок к прямому ($\alpha > 45^\circ$), пуля прошивает преграду насквозь! При этом её скорость падает пропорционально толщине сектора, а урон снижается на $35\%$, поражая укрывшегося за стеной противника.
2. **Геометрический рикошет (Ricochet):** Если пуля попадает в сверхпрочную бетонную стену или броню танка ([VEHICLE_SPEC.md](./VEHICLE_SPEC.md)) под острым касательным углом ($\alpha \le 20^\circ$), происходит математическое отражение вектора скорости с потерей $60\%$ энергии — шальная пуля отскакивает с характерным свистом в OpenAL и может ранить стоящего за углом врага.



## 📱 5. Оружейная витрина в Соцсети и Мобильный Конструктор

Оружейная система напрямую интегрирована в социальную сеть и приложение-компаньон ([SOCIAL_MESSENGER_SPEC.md](./SOCIAL_MESSENGER_SPEC.md) и [COMPANION_APP.md](./COMPANION_APP.md)):

1. **Интерактивные карточки оружия в Постах и Чатах:** Собрав уникальную пушку на верстаке, игрок может сгенерировать её `Share-Link` и отправить в групповой чат мессенджера или опубликовать на своей стене в соцсети. Друзья прямо со смартфона в интерфейсе `View/` могут вращать 3D-модель этой пушки на 360 градусов, кликать по каждому из 6 установленных модулей и смотреть графики падения урона на дистанции.
2. **Удаленный симулятор сборок (Theorycrafting в приложении):** Находясь вне дома, игрок может открыть вкладку «Оружейный Верстак» на Android, примерить имеющиеся у него на складе ([INVENTORY_SPEC.md](./INVENTORY_SPEC.md)) прицелы и стволы к своим винтовкам, рассчитать идеальную сборку с минимальной отдачей и сохранить пресет. При входе в игру на ПК верстак автоматически соберет оружие по сохраненному со смартфона чертежу!
