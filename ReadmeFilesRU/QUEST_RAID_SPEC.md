# 📜 Спецификация квестового движка, контрактов соцсети и подземелий-убежищ (QUEST_RAID_SPEC.md)

Статус: **целевой дизайн, не реализованная подсистема**. Общая сверка: [PROJECT_STATUS.md](./PROJECT_STATUS.md) / [PROJECT_STATUS.v2](./PROJECT_STATUS.v2); размеры схем: [SERIALIZATION_SPEC.md](./SERIALIZATION_SPEC.md) / [SERIALIZATION_SPEC.v2](./SERIALIZATION_SPEC.v2) (сырые правки токенов не считаются утвержденными без записи в `sql.core` и `memory.ctos` / `DECISIONS.md`).

Настоящий документ определяет архитектуру сюжетных и процедурных заданий, систему ветвящихся диалогов с NPC, биржу пользовательских контрактов (Player Bounties) и механику кооперативных рейдов в закрытые подземные комплексы. Подсистема объединяет доски объявлений и динамические миссии с таймерами из Borderlands 2, систему помощи поселениям и ролевых проверок параметров в диалогах из Fallout 4, а также многоуровневые подземные Убежища (Vault Raids) из Fallout 76.

Главная цель данной подсистемы — уйти от линейных триггеров «найди красный ключ и нажми кнопку выхода» оригинального Doom 2, заменив их нелинейным графом состояний в рантайме KINII (void.run), и позволить самим игрокам и лидерам кланов создавать оплачиваемые боевые контракты для других выживших прямо через Социальную Сеть и Мессенджер на смартфоне.

## 🏗️ 1. Системные и архитектурные связи

Квестовая подсистема связывает прогресс игрока, экономику и социальное взаимодействие через перекрестные ссылки:
* **Сохранение прогресса и выборов:** Граф выполненных квестов, убитых сюжетных персонажей и репутация фракций записываются в скрытые сектора HiddenVault через [sql.core](../Lang_for_my_decisions/sql.core) (ссылка на ветку: [://github.com](https://://github.com)).
* **Выдача наград и Эскроу-счета:** Выплата крышек, опыта и выдача редких пушек за выполнение заданий проходят через защищенные транзакции [INVENTORY_SPEC.md](./INVENTORY_SPEC.md) и [CLAN_SPEC.md](./CLAN_SPEC.md).
* **Проверка характеристик в диалогах:** Успех убеждения, запугивания или взлома терминалов во время квеста зависит от параметров S.P.E.C.I.A.L. и мутаций игрока из [SURVIVAL_SPEC.md](./SURVIVAL_SPEC.md).
* **Генерация целей в чанках:** Спавн квестовых боссов, потерянных грузов и маркеров на радаре координируется с [WORLD_DESIGN.md](./WORLD_DESIGN.md) и [MAP_SPEC.md](./MAP_SPEC.md).
* **Биржа наемников в Соцсети:** Публикация контрактов от игроков, прием заказов со смартфона и автоматические отчеты о выполнении работают через [SOCIAL_MESSENGER_SPEC.md](./SOCIAL_MESSENGER_SPEC.md) и [COMPANION_APP.md](./COMPANION_APP.md).

## 📊 2. Бинарные структуры Квестов и Пользовательских Контрактов

Все активные задания в памяти Ghost-RAM ([memory.ctos](../Lang_for_my_decisions/memory.ctos)) разделены на два типа: Сюжетно-процедурные квесты мира и Контракты, созданные самими игроками.

### 2.1 Структура Квестового Узла (Quest State Machine Node) — 64 байта packed / 64 байта native x64
```void
struct QuestStateMachineNode {
    u64 quest_uuid;           // Уникальный идентификатор задания в глобальной базе данных sql.core
    u8  quest_category;       // Тип: 0x01 = Сюжетка, 0x02 = Община (State of Decay style), 0x03 = Доска (Borderlands style), 0x04 = Рейд
    u8  _padding_0;           // Выравнивание структуры
    u16 current_stage_id;     // Текущий шаг графа выполнения (Шаг 10 = Поговорить -> Шаг 20 = Зачистить -> Шаг 30 = Включить)
    u16 branch_choice_mask;   // Битовая маска принятых моральных выборов (определяет концовку и отношение фракций)
    i32 target_chunk_xy[2];   // Координаты целевого чанка открытого мира [Cx, Cy]
    u32 objective_counter;    // Счетчик прогресса (например, убито 12 из 20 мародеров или собрано 3 из 5 ядер)
    u32 time_limit_sec;       // Таймер обратного отсчета до провала для срочных заданий (0 = бессрочный квест)
    u32 reward_seed;          // Крипто-зерно для процедурной генерации оружия в качестве награды из WEAPON_CRAFT_SPEC.md
    u64 _reserved_bytes[2];   // Зарезервировано для расширения состояний квеста до полного 64-байтного блока
}
```

### 2.2 Структура Пользовательского Контракта (Player Bounty Contract) — 88 байт packed / 96 байт native x64
Каждый наемный контракт, публикуемый в мобильной соцсети, содержит строгие лимиты, хэш-дескрипторы и замороженные буферы наград:
```void
struct PlayerBountyContract {
    u64 contract_uuid;            // Уникальный ID заказа на бирже мессенджера
    u32 issuer_clan_or_player_id; // Кто разместил заказ (ID игрока или UUID казны клана из CLAN_SPEC.md)
    u32 contractor_player_id;     // ID наемника/отряда, взявшегося за выполнение (0 = заказ свободен на доске)
    u8  contract_type;            // Тип задачи: 0x01 = Логистика, 0x02 = Зачистка, 0x03 = Охота (PvP Bounty), 0x04 = Эскорт
    u8  _padding_align[3];        // Выравнивание полей до границы 4 байт
    u64 escrow_reward_caps;       // Сумма оплаты в валюте/ресурсах, замороженная в Ghost-RAM (гарантия выплаты!)
    u32 target_objective_limit;   // Целевой лимит выполнения (например, доставить ровно 200 литров топлива)
    u32 contract_crc32;           // Контрольная сумма контракта против подделки условий со стороны клиента
    u64 _reserved_space[4];       // Свободные ячейки памяти для расширения параметров нативного x64
}
```

## ⚡ 3. Нелинейные Диалоги и Система Проверок (Fallout 4 / preRPG Style)

При разговоре с лидерами фракций или выжившими из [AI_FACTION_SPEC.md](./AI_FACTION_SPEC.md) в UZDoom открывается интерактивное окно диалога (4 варианта ответа с поддержкой горячих клавиш 1, 2, 3, 4):

### 3.1 Проверки характеристик S.P.E.C.I.A.L. и Перков:
* **[Харизма 7+]** — Убедить торговца снизить цену или мирно договориться с патрулем рейдеров без стрельбы и потери прочности брони.
* **[Интеллект 8+ / Перк Инженер]** — Заметить поломку в реакторе NPC и предложить быстрый ремонт из деталей [BASE_ENGINEERING_SPEC.md](./BASE_ENGINEERING_SPEC.md), получив двойную награду.
* **[Сила / Силовая Броня]** — Запугать мародера одним своим видом в экзоскелете из [COMBAT_EXO_SPEC.md](./COMBAT_EXO_SPEC.md), заставив его отдать ключ от склада без боя.

### 3.2 Влияние репутации:
Если ваш клан ранее разграбил караван этой фракции, мирные ветки диалога блокируются, а NPC при виде игрока сразу достает оружие и вызывает подкрепление по рации.

## 🤝 4. Биржа Наемников в Соцсети: Контракты от Игроков (Эскроу-Механика)

Главная социальная фича квестовой системы — игроки сами создают контент и работу для других игроков через приложение на смартфоне ([SOCIAL_MESSENGER_SPEC.md](./SOCIAL_MESSENGER_SPEC.md)):

```text
    [Заказчик на Смартфоне] ──(Создает пост-контракт + Заморозка награды)──► [Эскроу-Банк в sql.core]
                                                                                    │
    [Наемник в игре UZDoom] ◄──(Выполняет условие в чанке: Доставка/Убийство)──────────┘
            │
            └──► Рантайм void.run автоматически переводит награду наемнику без участия заказчика!
```

### 4.1 Как работает защита от обмана (Smart-Contract Escrow)
1. **Публикация в Ленте:** Лидер клана сидит на работе с телефоном и видит по камерам базы ([BASE_ENGINEERING_SPEC.md](./BASE_ENGINEERING_SPEC.md)), что в генераторах заканчивается бензин, а сам он зайти в игру с ПК не может. Он открывает в приложении компаньона вкладку «Биржа Контрактов», выбирает задачу: «Доставить 200 литров топлива в бункер чанка `[X:3, Y:-5]`» и назначает награду — например, редкий фиолетовый оптический прицел со своего личного склада.
2. **Заморозка в Эскроу:** Как только контракт опубликован, рантайм KINII на сервере мгновенно блокирует этот прицел на складе заказчика (`memory.lock_item_slots()`). Заказчик физически теряет возможность забрать награду назад, продать её или обмануть исполнителя!
3. **Автоматический расчет:** Любой свободный игрок на сервере видит этот пост в ленте соцсети, жмет «Взять заказ», приезжает на пикапе ([VEHICLE_SPEC.md](./VEHICLE_SPEC.md)) к базе заказчика и сливает 200 литров бензина в приемный клапан снаружи забора. Сервер фиксирует выполнение условия `objective_counter == 200` и в ту же секунду пересылает фиолетовый прицел в инвентарь наемника по правилам [INVENTORY_SPEC.md](./INVENTORY_SPEC.md), а заказчику на телефон приходит пуш: *«✅ Контракт выполнен! Ваша база заправлена на 100%»*.

## 🕳️ 5. Подземные Рейды в Убежища и Бункеры (Vault Raids на 4 Игроков)

Помимо открытого мира на поверхности, в некоторых чанках находятся массивные гермодвери с шестеренками — входы в заброшенные довоенные Убежища и Лаборатории Корпораций (аналог данжей из Fallout 76 и Borderlands 2):
1. **Изолированная генерация этажей:** Как и интерьер шагающего «Императора» ([EMPEROR_TITAN_SPEC.md](./EMPEROR_TITAN_SPEC.md)), подземное Убежище подгружается как отдельный многоэтажный лабиринт секторов UZDoom с повышенной плотностью ловушек, радиации и элитных мутантов за пределами стандартных чанков поверхности.
2. **Кооперативные головоломки под расчет времени:** Чтобы открыть путь в главное хранилище Убежища, отряду из 4 человек нужно действовать синхронно — например, двое игроков удерживают рубильники питания в затопленном машинном зале, третий взламывает терминал, а четвертый отстреливает волны светящихся гулей из турели.
3. **Механика «Один шанс на эвакуацию»:** В самых сложных режимах (Хардкор-Рейд) внутри Убежища отключено возрождение. Если напарник падает без сознания, его нужно реанимировать дефибриллятором из [SURVIVAL_SPEC.md](./SURVIVAL_SPEC.md) за 30 секунд. Весь вынесенный из глубин Убежища уникальный лут автоматически формирует красивую карточку отчета о рейде, которую можно в один клик опубликовать на стене своего клана в соцсети.
