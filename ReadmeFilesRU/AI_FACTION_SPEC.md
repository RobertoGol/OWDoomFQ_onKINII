 # 🤖 Спецификация искусственного интеллекта, общины выживших, фракций и рейд-боссов (AI_FACTION_SPEC.md)

Настоящий документ определяет математическую модель поведения неигровых персонажей (NPC), алгоритмы поиска пути в динамическом открытом мире, механику психологического состояния поселенцев на базе и архитектуру многофазных боссов. Подсистема объединяет в себе глубокий менеджмент общины выживших и архетипы особых мутантов из **State of Decay 2**, систему назначения поселенцев на работы и торговые караваны между базами из **Fallout 4**, а также сложные боевые паттерны Рейд-Боссов для кооператива на 4 игроков из **Borderlands 2**.

Главная цель данной подсистемы — полностью отказаться от примитивного шагового автомата `A_Chase` классического движка Doom 2 (где монстры просто шли по прямой в стену), вынеся обсчет ИИ, навигационных сеток (NavMesh) и симуляции жизни в асинхронные потоки рантайма **KINII (`void.run`)** с использованием эвристических матриц из директории `/Learning`.

---

## 🏗️ 1. Системные и архитектурные связи

Подсистема ИИ и фракций напрямую взаимодействует с остальными модулями проекта через систему перекрестных ссылок:
* **Машинное обучение и эвристика:** Весовые коэффициенты для принятия тактических решений ботами и мутантами подгружаются из моделей директории `/Learning`.
* **Навигация в чанках и разрушаемость:** Перестроение маршрутов обхода при разрушении стен (`LINE_DESTRUCTIBLE`) или постройке новых баррикад опирается на геометрию из [WORLD_DESIGN.md](./WORLD_DESIGN.md).
* **Реакция на звук и миграция орд:** Триггеры агрессии монстров привязаны к математической модели акустических волн (выстрелы, взрывы, рев моторов) из [MAP_SPEC.md](./MAP_SPEC.md).
* **Снаряжение и лут NPC:** Оружие в руках враждебных рейдеров и охранников базы генерируется по правилам [WEAPON_CRAFT_SPEC.md](./WEAPON_CRAFT_SPEC.md), а трофеи с Рейд-Боссов — через таблицы [INVENTORY_SPEC.md](./INVENTORY_SPEC.md).
* **Здоровье и травмы NPC:** Боты и боссы используют ту же 6-зональную био-матрицу конечностей (можно отстрелить лапу мутанту или выбить оружие из рук рейдера), что зафиксирована в [SURVIVAL_SPEC.md](./SURVIVAL_SPEC.md).
* **Мобильный менеджмент общины:** Распределение выживших на работы, урегулирование конфликтов и отправка отрядов NPC на авто-вылазки выполняются со смартфона через [SOCIAL_MESSENGER_SPEC.md](./SOCIAL_MESSENGER_SPEC.md) и [COMPANION_APP.md](./COMPANION_APP.md).

## 📊 2. Бинарные структуры данных NPC, Выживших и Боссов

Состояние каждого уникального NPC общины или крупного босса сериализуется в защищенной памяти `Ghost-RAM` (`memory.ctos`) и сохраняется в скрытых секторах `HiddenVault` (`sql.core`), чтобы мир оставался персистентным.

### 2.1 Структура Выжившего Общины (Community Survivor Node) - 80 байт
```void
struct SurvivorNPCNode {
    u64 npc_uuid;               // Уникальный мировой идентификатор выжившего
    u32 assigned_clan_id;       // ID клана/базы, к которой приписан выживший (связь с CLAN_SPEC.md)
    char npc_name[24];          // Сгенерированное имя и прозвище (UTF-8)
    
    // Профессиональные навыки и психология (State of Decay 2 Mechanics):
    u8  profession_id;          // Специализация: 0x01=Хирург, 0x02=Автомеханик, 0x03=Агроном, 0x04=Снайпер-охранник
    u8  skill_level;            // Уровень мастерства (1..10 звезд)
    u16 personality_traits_mask;// Битовая маска черт характера (Бит #0: Лидер, Бит #1: Клептоман, Бит #2: Паникёр)
    f32 morale_level;           // Уровень морали (-100.0 = Бунт/Побег с базы .. +100.0 = Вдохновение и бонус к крафту)
    f32 fatigue_and_hunger;     // Накопленная усталость и голод (требует списания еды со склада)
    
    // Текущая задача и пространственная привязка:
    u8  current_job_state;      // 0x00=Отдых в казарме, 0x01=На сторожевой вышке, 0x02=Караван, 0x03=В экспедиции за лутом
    i32 current_chunk_xy[2];    // Координаты чанка, где сейчас физически или виртуально находится NPC
    u64 equipped_weapon_uuid;   // Ссылка на выданную игроком пушку из INVENTORY_SPEC.md
    u32 node_crc32;             // Контрольная сумма структуры в Ghost-RAM
}
```

### 2.2 Структура Многофазного Рейд-Босса (Raid Boss Controller) - 64 байта
```void
struct RaidBossController {
    u64 boss_entity_uuid;       // Уникальный ID босса в сессии
    u16 boss_archetype_id;      // Тип (0x01=Кибер-Бегемот, 0x02=Матка Роя, 0x03=Бронированный Штурмовик Корпорации)
    u8  current_combat_phase;   // Текущая фаза боя (Фаза 1: 100-65% HP, Фаза 2: 65-30% HP, Фаза 3: <30% Enrage/Берсерк)
    u8  shield_element_type;    // Тип активного энергетического щита (пробивается только соответствующей стихией)
    
    f32 weakspot_hp_pools[4];   // Здоровье 4 уязвимых точек (например: 2 генератора на спине, визор, топливный бак)
    u32 aggro_table_players[4]; // Массив накопленной ненависти (Threat/Aggro) для каждого из 4 игроков кооператива
    u32 loot_table_seed;        // Крипто-зерно для гарантированного дропа Legendary предметов после смерти
}
```




### 2.2 Структура Механического Колосса (Colossus World-Walker Node) - 96 байт
В отличие от обычных акторов Doom (`AActor`), которые имеют один цилиндрический хитбокс, Колосс представляет собой **составной многосегментный объект (Multi-Actor IK Rig)** высотой более $1024$ юнитов (размером с пятиэтажный дом), чьи опоры обсчитываются инверсной кинематикой (IK) в рантайме KINII:

```void
struct ColossusWalkerController {
    u64 colossus_uuid;          // Уникальный мировой идентификатор гиганта
    u16 machine_class_id;       // 0x01=Сборщик Ресурсов (Harvester), 0x02=Шагающий Бастион (ARC-Queen Type)
    
    // Состояние пассивности и триггеры пробуждения:
    u8  behavior_state;         // 0x00=Пассивный патруль, 0x01=Желтая тревога (Сканер), 0x02=Пробуждение (Тотальная зачистка)
    f32 provocation_meter;      // Шкала раздражения (от 0.0 до 100.0%). Растет только при прямом уроне или краже его ядер!
    
    // Пространственная кинематика гиганта (Inverse Kinematics):
    f32 core_pos_xyz;        // Координаты центрального купола/реактора на высоте ~800 юнитов
    f32 leg_foot_xyz;     // Точные координаты 6 шагающих опор на рельефе чанка (каждая нога — отдельный хитбокс)
    
    // Зональная прочность узлов (Отстреливаемые модули брони):
    f32 leg_hydraulic_hp;    // Прочность гидравлики каждой из 6 ног (при 0% колосс оседает на колено)
    f32 laser_turret_hp;     // Прочность оборонительных турелей на корпусе
    f32 main_reactor_hp;        // Здоровье центрального ядра (открывается только при перегреве или падении на землю)
    
    u32 route_waypoints_ptr;    // Ссылка на глобальный маршрут движения гиганта через всю карту (MAP_SPEC.md)
}
```

## 🧠 3. Замена `A_Chase`: Архитектура ИИ и Навигации в Открытом Мире

В оригинальном Doom 2 функция `A_Chase` двигала монстра только по 8 фиксированным направлениям (север, северо-восток и т.д.) без понимания укрытий и высоты. В нашей архитектуре физика акторов UZDoom управляется **Двухуровневым ИИ-Планировщиком KINII**:

┌─── [ УРОВЕНЬ 1: ТАКТИЧЕСКИЙ ИИ (В РАДИУСЕ 3x3 ЧАНКОВ) ]
│    • Поиск пути A* по динамической сетке NavMesh (140 Гц)
│    • Поиск укрытий за LineDefs, стрельба с упреждением
[ ЯДРО ИИ KINII ]─┤
│
└─── [ УРОВЕНЬ 2: СТРАТЕГИЧЕСКАЯ СИМУЛЯЦИЯ (ДАЛЕКИЕ ЧАНКИ) ]
• Обсчет в фоновом потоке (1 Гц) без рендеринга в UZDoom
• Движение торговых караванов, миграция орд, экспедиции NPC


### 3.1 Полезность решений и Тактический бой (Utility AI & GOAP)
Для каждого вооруженного NPC (рейдеры, наемники фракций, выжившие-охранники) рантайм каждые $100\text{ мс}$ вычисляет оценку полезности действий $U_{action}$:
* **Уход за укрытие:** Если здоровье NPC падает ниже $40\%$ или по нему ведется подавляющий огонь из пулемета, вес действия $U_{cover}$ становится максимальным. Бот находит ближайшую глухую стену `LineDef` между собой и стрелком, приседает за ней и применяет стимпак.
* **Фланговый обход:** Если группа из 3 ботов-рейдеров видит, что игрок перезаряжается или лечит сломанную ногу ([SURVIVAL_SPEC.md](./SURVIVAL_SPEC.md)), один бот держит игрока под прицелом, а двое других строят маршрут обхода по соседним секторам, забрасывая позицию игрока гранатами.

## 🧟 4. Бестиарий Особых Мутантов и Механика Рейд-Боссов

Помимо обычных зараженных, в чанках открытого мира спавнятся специализированные мутанты (*State of Decay 2 Style*) и мировые боссы (*Borderlands 2 Style*):

### 4.1 Архетипы Особых Мутантов (Special Infected Hooks):
1. **Крикун (Acoustic Screamer):** Не имеет рук для ближнего боя. При обнаружении игрока издает ультразвуковой вопль, который:
   * Накладывает на всех игроков в радиусе $512$ юнитов эффект контузии (размытие камеры и звон в ушах).
   * Генерирует на карте [MAP_SPEC.md](./MAP_SPEC.md) экстремальный импульс шума ($I_0 = 500$), мгновенно вызывая спавн и стягивание всех орд из соседних чанков!
2. **Джаггернаут (Armored Behemoth):** Гигантский мутант с непробиваемой лобовой броней. Способен с разбегу проламывать построенные игроками стены баз (`LINE_DESTRUCTIBLE`) и переворачивать легкие багги из [VEHICLE_SPEC.md](./VEHICLE_SPEC.md). Уязвим только при попадании в спинной позвоночник или после подрыва на противотанковой мине.
3. **Ловкач / Сталкер (Shadow Hunter):** Передвигается прыжками по крышам секторов и 3D-полам UZDoom, использует оптическую маскировку и сбивает одиноких игроков с ног, требуя помощи напарника по кооперативу для освобождения.

### 4.2 Математика Агро (Threat System) и Фазы Рейд-Боссов
В бою против Рейд-Босса (рассчитанного на группу из 4 игроков) босс не бьет ближайшего человека, а выбирает цель по формуле динамической угрозы $T_{player}$:

$$T_{player} = (D_{dealt} \times 1.0) + (H_{healed} \times 1.5) - (Dist \times 0.2)$$

* Где $D_{dealt}$ — нанесенный урон за последние 10 секунд, $H_{healed}$ — объем лечения союзников.
* **Смена фаз и отстрел деталей:** Чтобы снять неуязвимость с Рейд-Босса на Фазе 2, стрелок на крышевой турели автомобиля или снайпер отряда должен прицельно уничтожить его генераторы охлаждения (`weakspot_hp_pools`), после чего босс впадает в состояние перегрева, открывая ядро для критического урона.

## 🏕️ 5. Жизнь Общины на Базе, Караваны и Интеграция с Мессенджером

Спасенные в открытом мире выжившие переселяются на базу клана ([CLAN_SPEC.md](./CLAN_SPEC.md)), превращая её в живой поселок:

1. **Назначение на роли и Производство (Fallout 4 + State of Decay 2):**
   * Выживший с профессией **«Автомеханик»**, назначенный в гараж базы, автоматически чинит припаркованные машины клана (`engine_hp` и `chassis_armor_hp` в [VEHICLE_SPEC.md](./VEHICLE_SPEC.md)) и крафтит ремкомплекты.
   * Выживший **«Снайпер»** физически поднимается на построенную игроками сторожевую вышку в UZDoom и круглосуточно отстреливает подходящих к забору одиночных монстров, расходуя патроны со склада базы.
2. **Психология, Мораль и Конфликты в Чате:**
   * Если на складе базы заканчивается еда или игрок долго не заходит в игру, мораль выживших (`morale_level`) падает.
   * Выживший с чертой характера *«Клептоман»* или *«Паникёр»* при низкой морали может устроить ссору. При этом **NPC сам пишет сообщение в клановый канал мессенджера ([SOCIAL_MESSENGER_SPEC.md](./SOCIAL_MESSENGER_SPEC.md))!** 
   * *Пример сообщения от бота-выжившего на смартфон игрока:* *«💬 [Выживший Маркус]: На базе крысы сожрали последние консервы, а ваш офицер забрал все патроны! Если до вечера не завезете провизию — я забираю медикаменты и ухожу из лагеря!»*
3. **Экспедиции и Авто-Вылазки со Смартфона (Companion Dispatch):**
   * Находясь на учебе или работе, игрок может открыть приложение-компаньон ([COMPANION_APP.md](./COMPANION_APP.md)), выбрать 3 свободных NPC-выживших на базе, выдать им со склада автоматы и нажать кнопку **«Отправить на зачистку чанка [X:2, Y:5]»**.
   * Рантайм сервера в фоновом режиме рассчитает симуляцию их похода (с учетом их уровня `skill_level` и качества оружия), а через 2 часа пришлет игроку в мессенджер полный текстовый лог боя и сложит добытый ими металлолом и редкие детали прямо в хранилище базы!
