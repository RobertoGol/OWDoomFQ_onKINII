## Объективные исправления этого прохода

- `CLAN_SPAC.md` переименован в `CLAN_SPEC.md`; существующие ссылки теперь совпадают с именем файла.
- Ссылки на отсутствующий соседний KINII-каталог указывают на зафиксированную GitHub-ревизию.
- `Ed25514` исправлен на `Ed25519`; подпись и обмен ключами не считаются одной операцией.
- Диапазон loot roll исправлен на `[0,9999]`: ровно 10000 исходов, Legendary — пять исходов.
- Скалярные поля, комментарии которых явно описывают массивы (`xyz`, шесть ног, две координаты чанка, название события), приведены к массивам.
- Размеры структур снабжены расчётом packed/native; динамические пакеты не называются фиксированными.
- Из оружейной спецификации удалён хвост переписки генерации, не являющийся требованием.
- Повторы аудио/энергетических разделов сведены к одному описанию; конфликтующие значения отправлены в реестр.

## Как принять решение

Для каждого ID зафиксировать выбранный вариант, владельца решения и дату; затем обновить связанные спецификации и тестовые критерии. До этого статус «предложено» не означает, что пользователь утвердил новый геймплей.
