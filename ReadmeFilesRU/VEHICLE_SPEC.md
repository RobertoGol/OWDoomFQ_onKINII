# 🚗 Спецификация физики транспорта, мульти-экипажей на 4 игрока и логистики (VEHICLE_SPEC.md)

Настоящий документ определяет физическую модель движения колесной и гусеничной техники, строгую систему распределения ролей экипажа (до 4 человек) и механику перевозки грузов в открытом мире. Подсистема объединяет в себе кооперативные боевые машины из **Borderlands 2**, разрушение преград и баллистику башенных орудий из **Battlefield**, а также сурвайвал-механику расхода топлива, поломки узлов при таране монстров и перевозки тяжелых контейнеров в багажнике из **State of Decay 2**.

Главная цель данной подсистемы — преодолеть отсутствие физики наклона объектов в секторном движке UZDoom, вынеся математический обсчет 4-точечной подвески, заносов и инерции шасси в изолированный рантайм **KINII (`void.run`)**.

---

## 🏗️ 1. Системные и архитектурные связи

Транспортная подсистема напрямую сшита с пространственными, боевыми и социальными модулями проекта:
* **Ускоренный стриминг чанков:** Поскольку транспорт перемещается в 3–4 раза быстрее пешего игрока, скрипт `world_stream.void` из [WORLD_DESIGN.md](./WORLD_DESIGN.md) динамически расширяет буфер предзагрузки секторов по вектору скорости машины.
* **Контейнер багажника и Топливо:** Багажное отделение автомобиля и канистры с бензином функционируют как защищенные массивы в `Ghost-RAM` по правилам [INVENTORY_SPEC.md](./INVENTORY_SPEC.md).
* **Баллистика турели и стрельба из окон:** Огонь, который ведут пассажиры и стрелок турели, обсчитывается с учетом собственного вектора скорости машины (сложение скоростей) по формулам из [WEAPON_CRAFT_SPEC.md](./WEAPON_CRAFT_SPEC.md).
* **Акустический профиль мотора:** Рев двигателя и разрушение препятствий генерируют мощные круги шума на интерактивной карте в [MAP_SPEC.md](./MAP_SPEC.md), провоцируя миграцию орд монстров.
* **Сетевая репликация экипажа:** Синхронизация координат 4 игроков внутри одного движущегося физического тела обеспечивается сетевым стеком [MULTIPLAYER_SPEC.md](./MULTIPLAYER_SPEC.md).
* **Оповещения и Музыка в салоне:** Уведомления противоугонной системы приходят в мессенджер, а общий музыкальный бот пати транслирует треки в салон машины через [SOCIAL_MESSENGER_SPEC.md](./SOCIAL_MESSENGER_SPEC.md).

## 📊 2. Бинарная структура транспортного средства (Vehicle State Entity)

Каждая машина в открытом мире персистентна (остается в том чанке, где её припарковали) и сохраняется в скрытой базе данных `sql.core` (`HiddenVault`) в виде строго выровненной 112-байтной структуры.

```void
struct VehicleEntityState {
    u64 vehicle_uuid;           // Уникальный мировой идентификатор транспортного средства
    u16 chassis_type_id;        // Тип шасси (0x01=Багги разведки, 0x02=Пикап с турелью, 0x03=Броневик отряда)
    u16 vehicle_flags;          // Флаги состояния (Бит #0: Фары вкл, Бит #1: Двигатель заведен, Бит #15: [РЕЗЕРВ ПОД ОРУЖИЕ ВОДИТЕЛЯ])
    
    // Пространственная физика шасси (обсчитывается в рантайме KINII 140 Гц):
    f32 world_pos_xyz[3];       // Точные мировые координаты центра масс (X, Y, Z)
    f32 velocity_vec[3];        // Вектор линейной скорости и инерции (Vx, Vy, Vz в юнитах/сек)
    f32 euler_angles[3];        // Углы Эйлера кузова: Yaw (Курс), Pitch (Тангаж на кочках), Roll (Крен в повороте)
    f32 wheel_compression[4];   // Сжатие 4 пружин подвески (0.0 = колесо в воздухе .. 1.0 = пробой до отбойника)
    
    // Эксплуатационные ресурсы и повреждения (State of Decay 2 Mechanics):
    f32 fuel_liters;            // Остаток топлива в баке (0.0 .. 100.0 литров)
    f32 engine_hp;              // Ресурс двигателя и радиатора (при <= 15% мощность падает вдвое, идет черный дым)
    f32 chassis_armor_hp;       // Прочность кузовных бронелистов
    u8  tires_intact_mask;      // Битовая маска 4 колес (0b1111 = все целы; прострел колеса сбрасывает бит в 0)
    
    // Строгая матрица экипажа (МАКСИМУМ 4 ЧЕЛОВЕКА):
    u32 crew_player_ids[4];     // [0]=Рулевой (Без оружия), [1]=Стрелок турели, [2]=Стрелок Лев.Окно, [3]=Стрелок Прав.Окно
    f32 turret_aim_angles[2];   // Независимые углы поворота башни/турели для Слота [1] (Yaw 360°, Pitch -15°..+60°)
    
    u32 trunk_inventory_ptr;    // Указатель в Ghost-RAM на инвентарь багажника (до 16 слотов под тяжелый лут)
    u32 state_crc32;            // Контрольная сумма структуры + MASTER_HWID хоста
}
```

## 👥 3. Архитектура мульти-экипажа (Строгий лимит: 4 Игрока)

Вся техника в проекте спроектирована под классический кооперативный отряд из 4 человек. При посадке в машину (`Use` на кузове) рантайм привязывает локальные координаты модели игрока к слоту автомобиля и применяет жесткие правила распределения ролей:

```

        [ ПЕРЕДНЯЯ ЧАСТЬ АВТОМОБИЛЯ (ДВИГАТЕЛЬ И ТАРАННЫЙ ОТВАЛ) ]
        ┌──────────────────────────────┬──────────────────────────────┐
        │ 🛞 СЛОТ: РУЛЕВОЙ         │ 🔫 СЛОТ: ПАССАЖИР СПРАВА │
        │ • Полный контроль шасси      │ • Стрельба из личного оружия │
        │ • Оружие: ЗАБЛОКИРОВАНО      │   через правое боковое окно  │
        │ • Взгляд: Камера вождения    │ • Сектор обстрела: 160°      │
        ├──────────────────────────────┴──────────────────────────────┤
        │               🎯 СЛОТ: СТРЕЛОК БАШЕННОЙ ТУРЕЛИ          │
        │               • Вращение крышевого орудия на 360°           │
        │               • Независимая стабилизация прицела            │
        ├──────────────────────────────┬──────────────────────────────┤
        │ 🔫 СЛОТ: ПАССАЖИР СЗАДИ  │ 📦 ГРУЗОВОЙ ОТСЕК (БАГАЖНИК) │
        │ • Стрельба из личного оружия │ • Хранение ящиков, канистр   │
        │   через левое окно / люк     │   и запчастей для базы       │
        └──────────────────────────────┴──────────────────────────────┘

```


### 3.1 Ролевые ограничения и механика слотов:
1. **Слот `[0]` — Рулевой (Водитель):**
   * Как только игрок занимает место водителя, рантайм KINII принудительно убирает его личное оружие в кобуру и блокирует пакеты стрельбы `NET_CL_SHOT` от этого `player_id`.
   * Задача рулевого — держать дорогу, объезжать аномалии, контролировать занос и давить монстров бампером.
   * *Архитектурный резерв:* В поле `vehicle_flags` зарезервирован бит `#15` (`DRIVER_WEAPON_UNLOCK`). В текущей версии он всегда равен `0`, что позволяет в далеком будущем при необходимости подключить курсовой пулемет или сброс мин без переделки сетевого протокола.
2. **Слот `[1]` — Стрелок крышевой турели (Borderlands / Battlefield Style):**
   * Управляет тяжелым стационарным вооружением машины (крупнокалиберный пулемет, автоматический гранатомет или трофейная плазменная пушка).
   * Турель имеет гироскопическую стабилизацию: когда водитель (`Slot 0`) резко поворачивает машину влево на $90^\circ$, ствол турели (`turret_aim_angles`) автоматически компенсирует этот угол, оставаясь наведенным ровно в ту точку пространства, куда целился стрелок!
3. **Слоты `[2]` и `[3]` — Стрелки в окнах (Бортовые стрелки):**
   * Сидят в салоне/кузове и используют своё собственное модульное оружие из [WEAPON_CRAFT_SPEC.md](./WEAPON_CRAFT_SPEC.md).
   * Могут высовываться из окон по нажатию правой кнопки мыши (прицеливание), получая сектор обстрела $160^\circ$ по своему борту, а также прямо на ходу применять стимпаки из [SURVIVAL_SPEC.md](./SURVIVAL_SPEC.md) или перезаряжать магазины.

## ⚙️ 4. Математическая физика подвески, заноса и тарана (Raycast Physics)

Классический движок Doom не умеет наклонять объекты по осям тангажа и крена (`Pitch` / `Roll`). Чтобы машина вела себя как реальный внедорожник на неровном рельефе чанков, ядро KINII обсчитывает физику через **4 луча подвески (Raycast Spring-Damper)**:

### 4.1 Формула работы амортизатора каждого колеса
В каждый тик из 4 углов днища машины вертикально вниз к полу сектора Doom выпускается математический луч длиной $L_{max}$. Если луч касается пола на расстоянии $L_{curr}$, сила выталкивания пружины $F_{spring}$ вверх рассчитывается по закону Гука с учетом гашения колебаний (демпфера) $C_{damp}$:

$$F_{spring} = K_{stiff} \cdot (L_{max} - L_{curr}) - C_{damp} \cdot V_{vertical}$$

* Когда правые колеса налетают на ступеньку или склон сектора в UZDoom, правая сторона машины подбрасывается вверх, меняя угол `Roll` 3D-модели кузова, а после прыжка с трамплина машина мягко приземляется, сжимая все 4 пружины без проваливания сквозь текстуры пола.
* **Прострел покрышек:** Если в колесо попадает пуля (сброс соответствующего бита в `tires_intact_mask`), длина луча $L_{max}$ этого угла уменьшается (машина проседает на обод), а коэффициент бокового сцепления падает с $0.85$ до $0.15$ — машину начинает сносить в неуправляемый дрифт на поворотах.

### 4.2 Кинематика Тарана монстров и разрушаемых стен (Ramming Logic)
Водитель (`Slot 0`), лишенный стрелкового оружия, использует саму массу автомобиля как главное оружие ближнего боя. При столкновении переднего бампера с актором монстра или разрушаемой стеной (`LINE_DESTRUCTIBLE` из [WORLD_DESIGN.md](./WORLD_DESIGN.md)) вычисляется импульсный урон тарана $D_{ram}$:

$$D_{ram} = \frac{1}{2} M_{chassis} \cdot |\vec{V}|^2 \cdot K_{bumper}$$

* Где $K_{bumper}$ — коэффициент усиления кенгурятника (отвал с шипами снижает отдачу по собственному двигателю `engine_hp` на $70\%$).
* При ударе на скорости свыше $800\text{ юнитов/сек}$ рядовые монстры мгновенно разлетаются с применением физики Ragdoll/спрайтового разрыва, однако если протаранить бетонный блок или тяжелого босса, машина получит критический урон радиатора и заглохнет посреди орды!

## 📱 5. Интеграция с Соцсетью, Мессенджером и Приложением-компаньоном

Транспорт напрямую связан с мобильной экосистемой проекта ([SOCIAL_MESSENGER_SPEC.md](./SOCIAL_MESSENGER_SPEC.md) и [COMPANION_APP.md](./COMPANION_APP.md)):

1. **Единое Авто-Радио и Музыкальный бот в салоне:** Когда 4 игрока садятся в одну машину, голосовой канал их группы в мессенджере синхронизируется с аудиосистемой салона. Если один из пассажиров включил трек в музыкальном плеере соцсети на своем смартфоне, эта музыка начинает играть из колонок автомобиля внутри UZDoom для всех четверых членов экипажа (и даже глухо слышна снаружи стоящим рядом игрокам!).
2. **Удаленный менеджмент багажника и GPS-маяк:** На интерактивной карте смартфона ([MAP_SPEC.md](./MAP_SPEC.md)) всегда отображаются иконки всех машин вашего клана, оставленных в открытом мире, с индикатором остатка бензина `fuel_liters`.
3. **Охранная сигнализация в Мессенджере:** Если чужой игрок на сервере пытается вскрыть багажник (`trunk_inventory_ptr`) или угнать припаркованную у руин машину вашей пати, бот сервера мгновенно присылает тревожное сообщение в групповой чат вашей четвёрки в мессенджере: *«🚨 ВНИМАНИЕ! Попытка взлома вашего Пикапа в чанке [X:7, Y:-1]! Остаток брони замка: 45%»*. Водитель может прямо из чата на телефоне нажать кнопку **«Блокировка зажигания»**, превратив машину в неподвижную стальную коробку до прихода своей группы!
